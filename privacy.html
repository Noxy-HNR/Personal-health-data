Privacy Policy

Last updated: August 23, 2026

Overview

Personal Health Data is a personal-use application created to access and analyze the owner's data from Oura Ring through the Oura API. The intended analysis is performed by AI models hosted by the owner on local hardware.

Data accessed

The application may access Oura data authorized by the account owner, including personal information and health, activity, sleep, heart-rate, workout, stress, blood oxygen, session, tag, ring configuration, resilience, cardiovascular-age, VO2 max, and related data available through the authorized Oura API scopes.

Use of data

Oura data is used solely for the owner's personal viewing, correlation, trend analysis, and AI-assisted analysis. The application does not sell personal data or use it for advertising.

Local processing

The local Oura service binds to the owner's local machine and is designed to pass Oura data to the owner's locally hosted AI environment. The application does not intentionally transmit Oura data to a hosted AI provider or other third party as part of its normal operation.

Sharing

Personal Oura data is not intentionally shared with third parties. If the owner independently configures another service to receive data from the local AI environment, that separate service is outside the normal operation of this application.

Credentials and tokens

The Oura client credentials and OAuth tokens are stored locally on the owner's machine. They are excluded from the application's public Git repository.

Data retention and deletion

The owner controls the application and may delete locally stored OAuth tokens and application data at any time. The application's disconnect function removes locally stored OAuth tokens. Oura authorization may also be revoked through Oura.

Contact

For questions about this application or its data practices, contact the application owner using the contact information associated with the Oura API application.
