Privacy Policy

Last updated: August 23, 2026

Overview

Personal Health Data is a personal-use application created to access the owner's Oura Ring data through the Oura API and provide deeper analysis using locally hosted AI models.

Data accessed

The application may access Oura data authorized by the account owner, including personal profile information and health, activity, sleep, heart-rate, workout, stress, blood oxygen, session, tag, and ring configuration data, depending on the OAuth scopes granted.

Use of data

Oura data is used solely for the owner's personal viewing, analysis, correlation, and related application functionality. The intended AI processing occurs on the owner's locally hosted models and local computer infrastructure.

Sharing

The application does not sell Oura data or use it for advertising. The local Oura service is designed to bind to the local computer and does not intentionally transmit Oura data to a third-party AI service.

Storage and retention

OAuth credentials and tokens used by the local service are stored on the owner's computer. The repository excludes the local credential and token files from version control. The owner controls locally stored health data and may delete it at any time.

Third-party service

Oura Cloud remains the source of the Oura data accessed by this application. Oura's own privacy practices and terms govern Oura's processing of data within its services.

Contact

For questions about this application or its data practices, contact the application owner using the contact information associated with the Oura API application.
