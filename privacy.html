Privacy Policy

Last updated: August 23, 2026

Overview

Personal Health Data is a personal-use application created to access and analyze the owner's data from Oura Ring through the Oura API.

Data accessed

The application may access Oura data authorized by the account owner, including personal profile information and health, activity, sleep, heart-rate, workout, stress, blood oxygen, session, tag, and ring configuration data, depending on the OAuth scopes granted.

Use of data

Data is used solely for the owner's personal viewing, analysis, and related application functionality. The application does not sell personal data or use it for advertising.

Sharing

Personal Oura data is not intentionally shared with third parties except where necessary to operate infrastructure or services explicitly configured by the owner.

Data retention and deletion

The owner controls the application and may delete locally stored application data at any time. Access can also be revoked through the Oura account.

Contact

For questions about this application or its data practices, contact the application owner using the contact information associated with the Oura API application.
